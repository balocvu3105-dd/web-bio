# CATAWUWA — OFFICIAL COMMUNITY BIO & LINKTREE

Dự án đã được cấu trúc theo chuẩn kiến trúc Hướng đối tượng OOP (Object-Oriented Programming) với các tính năng vượt trội:
- Hệ thống 4 Theme động với hiệu ứng chuyển cảnh Iris Wipe và màu sắc Neon độc quyền.
- Hiệu ứng Gợn sóng nước (Water Ripple Effect) & Hạt sáng 60 FPS viết trên ES6 OOP Classes (Particle, WaterRipple, VisualEngine).
- Cổng Cửa hàng 2 tầng (LootBar Shop & LDShop nạp game Wuthering Waves, Genshin, Arknights, NTE).
- Cổng YouTube 2 kênh (CataWuwa Livestream & Tấn - CataWuwa Cốt truyện).

CẤU TRÚC THƯ MỤC:
- index.html    -> Trang chủ Semantic HTML5
- css/style.css -> Hệ thống Glassmorphism & Modals CSS
- js/script.js  -> OOP Canvas Engine & Modal Controller
- README.md     -> Tài liệu hướng dẫn đầy đủ (vui lòng xem file README.md để có định dạng đẹp nhất)

HƯỚNG DẪN CHẠY:
1. Mở VS Code -> Mở folder `catawuwa-fixed`
2. Cài extension Live Server
3. Click chuột phải vào index.html -> Chọn "Open with Live Server"
