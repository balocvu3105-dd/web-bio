## 🚀 Giới Thiệu (About)
**CataWuwa Bio** là trang web Linktree & Portal cộng đồng chính thức được thiết kế theo phong cách hiện đại (**Ultra-Premium Glassmorphism & Cyberpunk Neon**). Trang web mang đến trải nghiệm thị giác sống động với hệ thống âm thanh, video nền từ YouTube và hiệu ứng tương tác thời gian thực 60 FPS.

---

## ✨ Tính Năng Nổi Bật (Key Features)

### 🎨 1. Hệ Thống 4 Theme Độc Quyền (Dynamic Theme Switching)
Tích hợp hiệu ứng chuyển cảnh **Iris Wipe Transition** siêu mượt cùng video nền YouTube động và màu sắc Neon đặc trưng cho từng nhân vật:
- 🌀 **Cartethyia (Aero)** — *Cyan Glow (`#00e5ff`)*
- 🔥 **Aemeath (Fusion)** — *Gold/Orange Glow (`#ffaa44`)*
- ❄️ **Hiyuki (Glacio)** — *Ice Blue Glow (`#aaddff`)*
- 💜 **Phrolova (Havoc)** — *Purple/Neon Glow (`#cc44ff`)*

### 🌊 2. Hiệu Ứng Tương Tác Mặt Nước (OOP Water Ripple & Particles Engine)
- **Hệ thống Hạt sáng (Particles)**: 60 hạt bụi sáng lơ lửng, phát sáng theo màu sắc của Theme hiện tại.
- **Hiệu ứng Gợn sóng nước (Water Ripple Effect)**: Click chuột vào bất kỳ đâu trên màn hình sẽ tạo ra 2 vòng sóng nước lan tỏa chuẩn vật lý 60 FPS được xây dựng trên kiến trúc **Hướng đối tượng OOP (ES6 Classes)**.

### 🛍️ 3. Hệ Thống Cửa Hàng & Nạp Game 2 Tầng (2-Tier Shop Portal)
- **Tầng 1**: Hiển thị lưu ý quan trọng trước khi nạp & lựa chọn hệ thống cửa hàng (**LootBar Shop** hoặc **LDShop**).
- **Tầng 2 (LDShop)**: Danh sách các game hỗ trợ nạp trực tiếp kèm Affiliate Link chính thức (*Wuthering Waves, Arknights: Endfield, Genshin Impact, Neverness to Everness*).

## 🛠️ Công Nghệ & Kiến Trúc (Tech Stack & Architecture)
- **Core**: Vanilla HTML5, Modern CSS3 (CSS Variables, Glassmorphism, Flex/Grid Layouts, Animations).
- **Logic & Effects**: Pure ES6 JavaScript với kiến trúc **Hướng đối tượng OOP (Object-Oriented Programming)** cho hệ thống `Particle`, `WaterRipple`, và `VisualEngine`.
- **Media**: YouTube Iframe API (Dynamic Video Backgrounds & Audio Controller).
- **Linter & Compatibility**: Chuẩn hóa CSS với đầy đủ vendor prefixes (`-webkit-mask`, `mask`, `background-clip`).

## 🎮 Hướng Dẫn Cài Đặt & Chạy Cục Bộ (Local Development)
1. Clone kho lưu trữ về máy:
   ```bash
   git clone https://github.com/balocvu3105-dd/web-bio.git
   cd web-bio
   ```
2. Mở dự án bằng **Visual Studio Code**.
3. Cài đặt tiện ích mở rộng **Live Server** (bởi Ritwick Dey).
4. Nhấp chuột phải vào file `index.html` -> Chọn **"Open with Live Server"** để trải nghiệm với tốc độ 60 FPS!
